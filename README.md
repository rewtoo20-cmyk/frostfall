# FROSTFALL 1.3.1
Пиксельная зимняя idle-RPG. Открой index.html в браузере (или запусти через лаунчер).

Загрузи в репозиторий ВСЕ файлы из этой папки (23 файла, включая новые модули FF: util, bus, anim, fx, audio, save, quests, expedition, forge, invasion, main, ffui).
Лаунчер сам скачает файлы из списка в version.json.

Клавиши (можно переназначить в Настройках): Пробел — удар, 1/2/3 — умения, F — полный экран, M — звук, F3 — отладка.
